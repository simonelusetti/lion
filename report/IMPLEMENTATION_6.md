# Experiment 6: conditional randomization of context

[Code](../lion/crt/), [Hydra config](../conf/crt/default.yaml). Exactly three arms: synthetic labels, EWT UPOS/deprel, and the four adjacent pairs, all with one bert-base-cased backbone and its own pretrained MLM head. No extra datasets, encoders, ablations, λ grids or classifier-seed repetitions.

**Population/scorers.** Tokenize raw EWT without truncation or added specials, preserving word-to-subword alignment. Eligible focals are words represented by exactly one subword. All eligible native-training words train three independent MLPs (768→256→labels, ReLU, dropout .1, AdamW lr .001 / decay .01 / clipping 1, seed 0). For each focal, encode its clipped ±16-subword window with CLS/SEP, at most 35 positions, using final-layer focal vectors. Cached vectors are fp16; inexpensive readouts train and produce log-probabilities in float32. Fix training at ten epochs, with no dev-based checkpoint selection because dev enters the CRT. Report accuracy on all eligible dev words.

CRT rows use one uniformly sampled eligible word per dev/test sentence, independently of labels and context-token identity, with fixed seed 20261117. Skip only sentences without eligible words. The inspected EWT corpus fits the full-sentence BERT limit (max 363 subwords); no length exclusions/truncation are required. Train, dev and test remain distinct. Native sentence/document IDs, focal positions and labels are saved.

**Synthetic labels.** On each eligible focal, OR the specified determiner set at −2 and preposition set at +1, treating out-of-sentence positions as false. Vocabulary sets include listed lowercase and initial-capital forms that actually exist. Independently flip labels with probability .1 using noise seed 123456. Labels are fixed before CRT sampling. True single non-null offsets are −2/+1; the (+2,+3) pair is null.

**Single draws.** For each valid offset −5..−1/+1..+5, mask that subword in the complete sentence with CLS/SEP, attention on. Run the same model’s MLM head at that position only. Compute float32 temperature-1 softmax after excluding tokenizer special IDs, equivalent to zeroing their probabilities and renormalizing. No vocabulary truncation. Draw K=200 with replacement; retain draws and entropy. Replace the target, re-encode the focal window, and read log probability of the original gold label. A row is included solely when the offset exists, with no token-identity filter.

**Pairs.** For (−3,−2), (−2,−1), (+1,+2), (+2,+3), mask both in the full sentence and sample the first. For each distinct sampled first value, fill it, mask the second, run one second MLM pass, and draw second values for its occurrences. Each resulting pair is re-scored on the window, for all three label sets. Store first entropy and every draw’s second conditional entropy; reported pair entropy is first entropy plus the draw-average second entropy, a Monte Carlo joint-entropy estimate for this chain.

**Numerics/efficiency.** Encoder/MLM uses fp16 and batches of up to 512 short windows / 64 full sentences, configured through runtime/Hydra. All three readouts share encoder passes and draw arrays. Identical sampled windows are scored once, then expanded to all K draws. Unchanged replacements copy the saved original statistic exactly, preserving ties under fp16 inference. No sampled draw is discarded. Draw RNG is fixed per sentence and tested condition, so benchmark reuse and sentence subsampling retain the same randomizations.

Per-row p=(1+count[T_resample≥T_original])/201, exact ties against rejection. Aggregate p uses the same formula on summed statistics. Numerically evaluate sums of paired differences to preserve exact zeros for unchanged samples; this is algebraically identical to comparing summed scores. z uses the sample SD across 200 aggregate randomizations; zero-dispersion z is undefined (nan) or signed infinity as appropriate. Effects are original minus mean resampled log probability; masking replaces the same single/pair positions with MASK. Entropy tercile cuts retain ties; empty strata are explicit.

**Budget.** Time ceil(1% of available sentence rows) for all single offsets, including UPOS, and for the pair arm. Encoder sharing means this timing also supplies the synthetic/deprel results. Print the measured total projection, including elapsed preparation/training time. If over three hours, repeatedly halve a fixed random permutation of sentence rows, never K. Retain all original training focals. Reuse benchmark draws/statistics in the final arrays, filtering them if the chosen pool is smaller. Window-input deduplication preserves the nominal 200 resamples exactly. Timing and the selected sentence pool are saved.

**Deliverables.** Raw condition files `results/crt/test/all/*.pt` contain row IDs, T_original [N,3], T_resample [N,200,3], T_mask [N,3], entropies, draws, tested positions and original tokens. `test/baseline.pt` retains full rows and metadata; `report/*.pt` retains derived per-row p/effects. The report contains dev scores, counts, measured wall-clock, Arm A rates at .05/.01 with binomial SEs and tie fractions, eight null-offset ten-bin histograms, aggregate p/z, Arm B and pair tables with single-offset p alongside, and entropy-tercile effects for all tasks/conditions. Summary text is factual. No multiple-testing adjustment is added to these diagnostic p-values.

One row per sentence is the specified sampling unit; sentences can share source documents. Binomial SEs treat sentence rows as independent. CRT finite-sample validity requires the sampler conditional to match the data conditional; the synthetic measurements assess its behavior rather than assuming correctness.

Forge/Hydra stages: prepare → cache all train/dev windows → train → time/select budget/test → report. Wall-clock includes all stages. `RESULTS_6.md`, this implementation, tables and histograms occupy the report root; the completed mask pilot is archived as batch 5.
