# Mask-rule pilot grid: implementation

[Code](../lion/pilot/), [config](../conf/pilot/default.yaml), [independent-cell grid](../grids/pilot_cells.yaml). Four tasks (EWT UPOS/deprel, GUM UPOS/discourse), five rotations each, seeds 0/1/2, 11 mandatory mask rules × none/cond: **1,320 evaluation cells**. The optional per-word-class selector is omitted; including it would give the prompt’s 12 rules. No requested fixed rule or regularizer is dropped.

**Sampling and masks.** Paired, fixed samples spread round-robin over documents within each genre/native split: up to 256/64/256 focals for native train/validation/test, at most two per sentence. Actual counts can be smaller. Training uses native training sentences from training genres; held validation/test genres use all native splits of the sample. ID validation/test use native validation/test of training genres. Frozen bert-base-cased block 12, first WordPiece, MLP 768→256→labels. All non-kept WordPieces become `[MASK]`, attention remains on, positions and length stay fixed. Every distinct masked input is re-encoded; deduplication only shares identical encoder inputs. Caches are shared across compatible EWT/GUM tasks, rotations, seeds and readouts.

Fixed masks are full, word, lin1/lin2, tree1/tree2, count-matched rand_tree1 and full_prev. Gold UD paths define tree masks even through source nodes not retained by tokenization. Random masks use only positions and gold-tree counts. Full_prev prepends the previous same-document, same-native-partition sentence, retaining whole-word suffixes that fit alongside the complete current cached sentence in 512 WordPieces. No cross-document or cross-partition predecessor is used. Missing/truncated predecessors are counted; position shifts are an H3 limitation. No rule uses the lexical content of a removable word at prediction time.

**Selection.** One independent scorer per task/rotation, seed 1729, trained on uniformly sampled slot subsets. Eight subsets per focal are cached; training draws uniformly from this pool. Checkpoint selection uses the held validation genre. Freeze the scorer, then evaluate all 256 slot subsets on native ID-validation tokens only. The eight slots are left1, right1, left2, right2, head, grouped dependents, grouped siblings and grandparent. Focal visibility is unconditional; overlaps/missing slots are handled by union.

Sel_suff minimizes slot count among subsets with CE ≤1.01×minimum CE, with CE/numeric-subset tie breaks. Invariance selectors minimize ID-validation CE among non-rejected subsets; no valid accepted subset means word-only fallback. Tests first average one-hot-label minus predicted-probability residuals within each document, then apply per-class one-way ANOVA, Bonferroni across the fixed label inventory, α=.05. Sel_inv_genre uses training genres. Sel_inv_free fits k-means on complete native-training document full-view means, K equal to the number of training genres; native ID-validation documents are assigned to frozen centers. No annotation defines its clusters, though the shared rotation/sampler still uses genre labels. The selected subset is global per task/rotation, shared across seeds/penalties. ICP intersection is the bitwise intersection of accepted subsets, descriptive only.

**Training and λ.** AdamW lr .001, decay .01, dropout .1, per-head clipping 1; genre-balanced sentence batches (nominal 64), identical initialization/dropout/data across independent heads. Maximum 600 steps, validation every 50, patience three after 150 steps and one sampler pass; the cap always applies. Select each checkpoint by held-validation-genre macro-F1. For each task’s first rotation, a 100-step full-view baseline measures CE/conditional-covariance ratios on up to 12 batches. Use the median ratio times 10^{−1.5,−.5,.5,1.5}, plus shared λ=0. All three seeds fit these candidates; mean validation macro-F1 selects one λ per task, with smaller λ breaking ties. That λ is fixed for every rule/rotation; zero is allowed. Cond is exactly the previous Rg loss: squared Frobenius norm of batch cross-covariance between focal-label-centered log-probabilities and one-hot genre.

The 1,320 cells are trained in **60 vectorized fits**, with independently parameterized/checkpointed heads. Each also includes 20 dedicated random-subset readouts, shared subset IDs across rotations/tasks, to compare native ID-validation CE rankings against the frozen scorer. Mean Spearman <.5 flags poor scorer validity. The explicit Forge product grid can rerun cells individually after shared prerequisites.

**Measurements.** ID/OOD accuracy and fixed-label macro-F1; context gain against word under the same regularizer, and shrink = ID gain − OOD gain; ID-test document ANOVA F/Bonferroni p/rejection; within-label genre BA from log-probabilities; the same probe on mask shape alone (sentence length, focal position, kept count, eight actual kept-slot indicators). Mask geometry is standardized on training focals only. Probes use E3 class-balanced linear readouts, ten epochs, separate native ID-validation checkpoint selection and document-held-out ID-test folds (five EWT, two GUM). Pilot support minima are 8/4/4 per label×genre for train/validation/test in every fold; unsupported labels are excluded and support is reported. BA averages eligible genres within label, then labels equally.

Full-view calibration randomly assigns training-genre ID-test documents to balanced groups 100 times, with the same environment count, and reruns the test. Bonferroni can be conservative; a task-average null rejection rate >10% flags miscalibration. Scorer validity and calibration qualify selection evidence. Residual rejection can reflect estimation error; acceptance does not prove invariant conditionals or identify necessary slots.

**Comparisons and reporting.** H1–H5 use none; H6 is (cond−none) on full minus the same on tree1. H1 compares tree1/lin1 against full/random, plus tree1−lin1 on deprel. H3 requires a positive full_prev accuracy gain and lower rejection frequency. H4 compares sel_inv_genre to sel_suff and the per-rotation/seed OOD oracle best fixed rule. H5 uses a predefined ±.5 pp equivalence margin. Selection verdicts remain inconclusive if scorer ranking is poor or calibration fails. H2 residual-test patterns are recorded; they cannot by themselves distinguish causal explanations. All six hypothesis verdicts are listed per task, with no claim that non-significance proves equivalence.

Differences pair rotation/seed. Rotations aggregate equally; seed SD follows rotation averaging. Use 200 document-block bootstrap draws within ID genres / the held OOD genre, paired across cells; ANOVA and rejection are recomputed per draw. Intervals condition on fitted models, probes and selections. Cell CSVs retain actual p-values; task tables’ mean p-values are descriptive, not combined tests. Nominal H1–H6 contrast intervals are not adjusted across the hypothesis family. No bootstrap refitting or additional hypothesis families.

**Execution/artifacts.** Forge/Hydra tracks prepare → base cache → 20 scorers → selection → selected-mask cache → four λ pilots → 60 grid fits → analysis → report. Raw outputs: `results/pilot/`; encoder caches: `data/cache/pilot/` keyed by encoder/sampling settings. `grid.csv` enumerates all cells; checkpoints map cells to independent heads. Reports: IMPLEMENTATION_5.md, RESULTS_5.md, compact tables. Wall-clock includes all stages. Batch 4 is archived when this run starts.
