# Step 1b: diagnostics on regenerated sensitivity fills

Inference and analysis only. Reuse the full-scale scorer, g1/g2, cuts and all nine classifier checkpoints. Source step-1 files under results/sensitivity/ are preserved. No scorer/selector/classifier is trained or selected. Sections 2/3 remain on hold.

Step 1 saved filled focal vectors but no token IDs. The original generation function is reused with a passive token recorder: identical inputs, batch sizes, draw counts, seeds and sampling calls. The recorder consumes no RNG. Four calibration-style draws per word/mask/fold are regenerated under results/sensitivity_1b/. Then every per-draw S/flip is recomputed on these vectors. The baseline entity headline is compared with saved full-precision step-1 values and the supplied rounded values .1024/.1283; all deviations are reported, without substituting old measurements. Every analysis uses this one regenerated set.

Token arrays are ragged-packed per row. original_ids and word_ids use piece_offsets; selector_token_ids/random_token_ids contain four contiguous sequences per row, beginning at 4×piece_offsets[row]. Word-level drop flags use word_offsets. Original word slot segmentation is fixed. Changed words compare case-sensitive WordPiece strings concatenated within that slot, stripping continuation prefixes; alternate piece decompositions spelling the same word count as restored. No retokenization or case folding. Record per draw changed count, nearest changed-word distance (−1 for null), and full token IDs.

S remains gamma=.01 KL(original || filled) over nine native tags. For conditional non-null/bin analyses, average eligible draws within each fold, then available fold means within each word. A word with neither fold supported is excluded. To keep selector/random comparisons on identical rows, displayed conditional estimates use common word support for both masks; mask-specific all-null exclusions are also reported. Null draws are omitted, not assigned zero. Row SEs follow averaging; draws and folds are never independent rows. Baseline means/SD use three seeds. Scorer has one fitted model. All other arms and both transfer sets remain in CSVs only, marked UNCERTIFIED.

A reports word-weighted restoration fractions among dropped word occurrences, row-average changed counts and null-swap shares (including zero-drop identities), then common-cohort non-null S/flips. B uses fixed changed-count bins 0/1/2/3/4/5–9/10+ and nearest-distance bins 1/2/3/4–5/6–10/>10. Nulls have no nearest-distance bin. Both masks use identical bin edges and common within-bin word support. Dropped-distance distributions pool word positions across both selectors and use equal position weights. Matched ratios are computed inside count×distance cells on common words, then averaged using selector draw frequencies, renormalized over supported cells. Cells below 50 words or with undefined random-S denominator do not contribute ratios; retained selector mass is reported. Delta-method row SE conditions on the cell weights and accounts for repeated words across cells.

C/D metadata comes from original cached word forms and gold BIO tags. The training lexicon/entity spans use exactly the baseline’s 10,531 T1∪T2 sentences; scorer A is excluded. Exact case-sensitive gold span word tuples define seen status; B/I is ignored only for entity type matching. Entity rows retain the step-1 raw-scorer group. False-positive scorer-entity rows with gold O have no gold span and are listed separately rather than silently removed. Original error is token BIO error. For transfer CSVs, core type names are canonicalized (person→PER etc.); types outside the source vocabulary cannot be predicted. Ambiguity uses distinct training O/PER/LOC/ORG/MISC types for each exact word form.

For concentration, each mask supplies a ranking; each ranking evaluates both masks on the same top rows. Calculate flip shares at the top 1/5/10% separately for each seed, then mean/SD. Row SE conditions on the ranking. The main top-20 form lists use the baseline seed-mean S ranking over all words; seed/group-specific lists are saved as well. Small top sets are flagged. Bins under 50 rows are flagged throughout; no matched S ratios are computed for them.

The report contains CoNLL baseline/scorer tables only, with short factual descriptions. CSVs contain every arm/seed and all three datasets. Generation, measurement, analysis and total wall times are saved. Raw IDs: generate/{dataset}/{g1,g2}.pt; per-draw inference: measure/{dataset}_{classifier}_{seed}.pt; CSVs: analyse/. Source model checkpoints and step-1 arrays are unchanged.
